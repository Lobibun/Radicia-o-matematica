
Projeto educacional desenvolvido em Unity utilizando C#.

## Sobre o projeto

O projeto consiste em um jogo 2D que utiliza elementos de
gameplay para apresentar desafios relacionados à radiciação
matemática.

## Tecnologias

- Unity
- C#
- Programação Orientada a Objetos
- Git/GitHub

## Principais sistemas desenvolvidos

- Sistema de movimentação do personagem
- Sistema de perguntas e respostas
- Controle de estados do jogo
- Sistema de vitória e derrota
- Respawn do personagem
- Interação com elementos do cenário
- Sistema de menu

## Objetivo

O projeto foi desenvolvido como forma de aplicar conhecimentos
de programação, lógica e desenvolvimento de jogos utilizando
Unity e C#.
